NIMBARA — a travel poster for a place that isn't there. At sunset, grass-topped islands drift above a sea of cloud; on the largest isle stands a slender white lighthouse, its lamp lit and its beam sweeping toward the sun, while a waterfall pours off the island's edge and dissolves into the clouds below. Pure Python (standard library only), no network, deterministic — it draws the whole poster pixel by pixel and writes a 1024×1024 PNG.

## Run it

```sh
python3 main.py
```
